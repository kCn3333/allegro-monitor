# Logo

Znak aplikacji: lupa z książkami. Rozszerzenie używa kontrastowego wariantu na pomarańczowym tle.

| Pliki | Zastosowanie |
| --- | --- |
| `logo-source.png`, `logo-prompt.txt` | Oryginał logo i prompt. |
| `logo-{16,32,48,64,128,256,512,1024}.png` | Przezroczyste warianty PNG. |
| `favicon.ico` | Ikona karty, rozmiary 16, 32 i 48 px. |
| `apple-touch-icon.png` | Ikona Apple, 180 px. |
| `extension-icon-source.png`, `extension-icon-prompt.txt` | Źródło wariantu rozszerzenia i prompt. |

Po zmianie logo zaktualizuj używane kopie w `public/` i `extension/`. Rozszerzenie potrzebuje ikon 16, 32, 48 i 128 px. Zawartość paczki ZIP określa `src/extension-package.ts`.
